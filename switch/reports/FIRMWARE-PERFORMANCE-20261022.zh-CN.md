## 8. 方法与范围

- DE 参数：temperature=0、top_p=1、max_tokens=400、每次调用预热 2 次，再正式测 5 轮；不添加填满输出或 ignore_eos 指令。
- 每流速度：`(completion_tokens - 1) / (last_visible - first_visible)`；每轮每流列取排序后的上中位项，偶数并发不取两个中间值的平均。
- 聚合速度：`sum(completion_i - 1) / (max(last_i) - min(first_i))`，使用实际生成数。
- code 每个流使用不同代码任务；非 code 的并发提示添加 stream 后缀。跨并发不仅改变 batch，也改变提示组成。
- PR 每档三次 fresh salt，内置 512-token warmup，最多输出 8 token；旧档位先完成全部 PR 再进入 DE，新档位的次序与缓存历史不同。
- 本报告范围是 C1/C2/C4/C8 四型 DE 与三档新固件串行 PR，没有追加推理请求；未执行 C16 满载、600K 全长质量或 9.6M KV 满池驻留/召回。
